# 00. Обзор

Основной пользовательский мануал для `org.agty.sql`.

Документ описывает текущий публичный API библиотеки и основные сценарии:

- инициализация и конфигурация;
- high-level CRUD;
- `Arguments.builder()`;
- low-level JDBC/session API;
- cursor/streaming;
- transaction control;
- cross-db ограничения;
- migration notes.

Если нужен низкоуровневый session/JDBC контракт отдельно, см.
`docs/AGTYSQL_SESSION_API.md`.

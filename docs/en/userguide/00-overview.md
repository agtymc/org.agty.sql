# 00. Overview

Main user guide for `org.agty.sql`.

This guide documents the current public API and the main usage scenarios:

- initialization and configuration;
- high-level CRUD;
- `Arguments.builder()`;
- low-level JDBC/session API;
- cursor/streaming;
- transaction control;
- cross-database limitations;
- migration notes.

For a separate low-level session/JDBC contract, see
`docs/en/AGTYSQL_SESSION_API.md`.
